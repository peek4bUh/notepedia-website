# TCP and UDP Ports

| Port  | UDP | TCP | Description              |
| ----- | :-: | :-: | ------------------------ |
| 20    |  -  | ✔️  | FTP data transfer.       |
| 21    |  -  | ✔️  | FTP command control.     |
| 22    |  -  | ✔️  | [[001R\|SSH]].           |
| 23    |  -  | ✔️  | Telnet.                  |
| 25    |  -  | ✔️  | SMTP                     |
| 80    | ✔️  | ✔️  | HTTP                     |
| 161   | ✔️  | ✔️  | SNMP                     |
| 389   | ✔️  | ✔️  | LDAP                     |
| 306   |  -  | ✔️  | mariadb.                 |
| 445   |  -  | ✔️  | SMB.                     |
| 873   |  -  | ✔️  | rsync                    |
| 3389  |  -  | ✔️  | Remote Desktop Protocol. |
| 5985  |  -  |     | WinRM.                   |
| 6379  |  -  | ✔️  | Redis.                   |
| 27017 |  -  | ✔️  | MongoDB server.          |
