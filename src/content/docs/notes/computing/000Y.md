# Connect to a Known Network using wpa_supplicant Manually

## Start the wpa_supplicant in the background

You need a **root shell**:

```
# wpasupplicant -B -i interface -c <(wpapassphrase "MYSSID" "passphrase")
```

## Request an IP address from a DHCP server

```
# dhclient
```

note: [https://stackoverflow.com/questions/63961142/what-does-dhclient-do](https://stackoverflow.com/questions/63961142/what-does-dhclient-do)
