# Change Folder Path in Syncthing

## Paths

### New

- `$XDGSTATEHOME/syncthing`
- `$HOME/.local/state/syncthing`
- `$HOME/Library/Application Support/Syncthing`
- `%LOCALAPPDATA%\Syncthing`

### Old Paths in Unix-like:

- `$XDGCONFIGHOME/syncthing`
- `$HOME/.config/syncthing`

## Update Folder Path

- Stop the syncthing service.
- In your system rename the folder.
- Edit the file `config.xml` and update the path of the folder you changed in you system.
- Start the syncthing service.

### Old

```xml
<configuration version="36">
	<folder
		...
		label="SYNCTHINGFOLDERNAME"
		path="OLD_PATH >
		...
	</folder>
	...
</configuration>
```

### New

```xml
<configuration version="36">
	<folder
		...
		label="SYNCTHINGFOLDERNAME"
		path="NEW_PATH" >
		...
	</folder>
	...
</configuration>
```
