# Update System using APT GET

```bash
# Updates repositories and available
# packages to prepare for OS/tool update
apt-get update

# Install newer versions of packages if
# available (checks results of apt-get update)
apt-get upgrade

# Intelligently updates system, updating
# dependencies and removing older obsolete
# packages as needed
apt-get dist-upgrade
```
