# How does ARP work?

- Each network device stores a table of identifiers know as **cache** (IP & MAC addresses).
- [[Computing/Networking/20241101182042|ARP Protocol]] maps **IP addresses to MAC addresses** using two messages:
     - **ARP Request**: Broadcasts a query for a specific IP’s MAC address.
     - **ARP Reply**: The matching device responds with its MAC address.
- The requesting device stores the response as an **ARP entry** for future use.
