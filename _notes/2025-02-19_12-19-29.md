# Operating System Information

```bash
# Disk usage
df -h

# Kernel Version & CPU Info
uname -a

# Display OS Info
cat /etc/*release*

# Display Kernel Info
cat /proc/version

# Locate the executable files or location
# of each shell on the system
which <SHELL_NAME>

# Display connected drives
fdisk -l
```
