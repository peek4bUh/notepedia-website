# Connect to a Known Network using wpa_supplicant At Boot

## Create a minimal Config File using wpa_passphrase

You need a **root shell**:

```
# wpapassphrase "MYSSID" "passphrase" > /etc/wpasupplicant-wlan0.conf
```

## Enable and Start the Service (need to renew ip address)

```
# systemctl enable wpa_supplicant@wlan0.service
# systemctl start wpa_supplicant@wlan0.service
```
