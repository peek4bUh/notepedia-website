# File Transfer Protocol

- A long-used protocol for **file transfers** (manual & automated) across operating systems.
- Allows users to **upload/download** files between a **client** (user’s device) and a **server**.
- Traffic is **unencrypted**, making it vulnerable to **Man-in-the-Middle (MitM) attacks**.
- Can be secured by:
     - **SSL/TLS** encryption.
     - **Tunneling through SSH** for a secure transfer.
