# Dynamic Host Configuration Protocol

- [[20240921163105|IP addresses]] can be assigned **manually** or **automatically**.
- If automatically assigned, a device sends a **DHCP Discover** request to find a DHCP server.
- The DHCP server responds with an available IP (**DHCP Offer**).
- The device confirms the selection (**DHCP Request**).
- The DHCP server finalizes the process (**DHCP ACK**), and the device can use the IP address.
