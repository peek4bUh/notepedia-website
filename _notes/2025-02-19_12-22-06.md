# Manipulate Packages using RPM (RED HAT)

```bash
# List all installed Redhat Packages
rpm -qa

# Install all Red Hat packages with a
# filename ending in .rpm
rpm -ivh *.rpm

# Remove Red Hat Package
rpm -e <PACKAGE_NAME>
```
