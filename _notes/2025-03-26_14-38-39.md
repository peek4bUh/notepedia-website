# Windows 10 make UAC always require password

## 1. Prompt with always Password

- `Windows + R` and type `regedit`.
- Paste this in the search bar:

```
Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
```

- Right click in `ConsentPromptBehaviorAdmin` and select `Modify`.
- Paste this value `00000001` in **hexadecimal**.

## 2. Prompt Without Password

- `Windows + R` and type `regedit`.
- Paste this in the search bar:

```
Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
```

- Right click in `ConsentPromptBehaviorAdmin` and select `Modify`.
- Paste this value `00000005` in **hexadecimal**.
